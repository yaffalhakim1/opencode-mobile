Run your agent from the sofa.

OpenCode Mobile talks to the OpenCode server on your machine. You watch the reply arrive word by word, answer when it asks you something, and approve the files it edits.

How it handles a turn

An agent turn is reasoning, tool calls and prose, interleaved, sometimes stopping to ask you a question. The interface follows that shape.

Ten steps, one panel

Reasoning and tool calls share a surface with a hairline between rows. A long run stays compact, so the prose is what you read. Each row says what happened ("Ran command", "Edited file") and marks it with a check when it succeeded.

It asks, you answer

When the agent needs a decision it blocks the turn and waits. Questions and permission requests arrive as cards with their real choices, including which pattern "Always allow" would remember.

Long sessions stay navigable

A session opens at the newest turn. Scroll up to page back through history. Group by project or by when you last touched it, filter to what is running, and start a new session in a chosen project.

What it leaves out

This is a client for a server you run. It has no account, no sync, and no cloud of its own.

  • ✓No account. Pair by scanning a code or entering the address and password your server prints.
  • ✓No traffic of its own. It talks to the host you gave it, on your LAN or through a tunnel you control.
  • ✓No plaintext credential. The server password is sealed with an AES-256-GCM key held in the Android keystore.
  • ✓No model of its own. The agent, model and reasoning effort come from your server.

Install

Every release publishes a signed APK. There is no Play Store listing; sideloading is the distribution model. 

# on your phone, with the APK downloaded
adb install -r opencode-mobile-v1.0.8.apk

Uninstall any earlier build first. Android rejects an update signed with a different key. 

# on your machine, then scan the QR it prints
opencode serve --hostname 0.0.0.0 --port 4096

# or point the app at the printed URL and password
