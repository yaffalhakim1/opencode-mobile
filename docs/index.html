Your agent, in your pocket. Not in someone’s cloud.

OpenCode Mobile is a native client for the OpenCode server already running on your machine. Watch the reply stream in, answer when the agent asks you something, and approve the files it touches — from the sofa.

Built around how an agent actually works

An agent turn is not a chat message. It is reasoning, tool calls and prose, interleaved, sometimes pausing to ask you a question. The interface is shaped around that, not around a messenger.

A turn is one card, not ten

Reasoning and tool calls share a single surface with a hairline between rows, so a run of ten steps stays compact and the prose is what you read. Each row says what happened — “Ran command”, “Edited file” — with a check mark when it succeeded.

It asks, you answer, it continues

When the agent needs a decision it blocks the turn and waits. Questions and permission requests appear as cards with their real choices — including which pattern “Always allow” would remember.

Long sessions stay navigable

Open at the newest turn, not the first. Scroll up to page back through history. Group by project or by when you last touched it, filter to what is running, and start a new session in a specific project.

What it deliberately does not do

This is a client for a server you run. It has no account, no sync, and no cloud of its own.

  • ✓No account. Pair by scanning a code or entering the address and password your server already prints.
  • ✓No traffic of its own. It talks only to the host you gave it — your LAN address, or a tunnel you control.
  • ✓No plaintext credential. The server password is sealed with an AES-256-GCM key held in the Android keystore.
  • ✓No model of its own. The agent, the model and the reasoning effort are the ones your server has.

Install

The APK is signed and published on every release. It is not on the Play Store; sideloading is the whole distribution model. 

# on your phone, with the APK downloaded
adb install -r opencode-mobile-v1.0.6.apk

If a build is already installed, uninstall it first — the signature must match. 

# on your machine, then scan the QR it prints
opencode serve --hostname 0.0.0.0 --port 4096

# or point the app at the printed URL and password
